## Layout
```
main.tex            IEEEtran skeleton; \input's sections/ and the generated artifacts
tr.tex              companion TECHNICAL REPORT (response plan section 13): the procedures, sensitivity
                    analyses and per-system tables the paper cites as "TR section N" (	rX macros in
                    main.tex); built from the SAME macros/tables, so no number is retyped; `make tr`
shared/             prose shared by main.tex and tr.tex (the terminology paragraph)
sections/           one .tex per section (hand-written prose; cites generated macros)
references.bib      related work — every entry verified against DBLP/Crossref/arXiv on 2026-08-30
                    (plans/notes/2026-08-30-related-work-search-update.md); re-check arXiv-only entries at camera-ready
tables/             GENERATED by analysis/make_tables.py  (committed, never hand-edited)
figures/            GENERATED by analysis/make_figures.py (committed, never hand-edited)
figures-hand/       hand-drawn figures (TikZ pipeline overview for Sec. III) — edit these
generated/macros.tex GENERATED by analysis/make_macros.py — every in-prose number
Makefile            `make` to build; `make data` to regenerate tables/figures/macros
```

## The reproducibility rule
**No number, table, or figure in the paper is hand-typed.** Prose cites
`\newcommand` macros from `generated/macros.tex`; tables/figures are emitted from
`analysis/results.csv` (the tidy aggregate of all `out/**` raw runs). A data
refresh re-typesets the paper. See plan §15 for the full pipeline:

```
out/**  --aggregate_results.py-->  results.csv
                                      ├── stats.py        -> stats.json
                                      ├── make_tables.py  -> latex/tables/*.tex
                                      ├── make_figures.py -> latex/figures/*.pgf
                                      └── make_macros.py  -> latex/generated/macros.tex
make  ->  main.pdf
```

## Build
```
make            # build main.pdf (uses the committed generated artifacts)
make tr         # build tr.pdf, the companion technical report (same generated artifacts)
make data       # regenerate tables/figures/macros from analysis/results.csv first
```
Requires a TeX distribution with `latexmk`, `IEEEtran`, `booktabs`, `siunitx`,
`pgf`. `make data` requires the Python `analysis/` pipeline and a populated
`out/**` (or the archived replication package).
